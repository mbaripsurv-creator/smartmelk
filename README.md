# SmartMelk

SmartMelk is a Telegram-first intelligent real-estate management platform.

## Vision

SmartMelk helps real-estate agencies manage:

- Agencies
- Managers
- Agents
- Customers
- Properties
- Customer requirements
- Tasks
- Visits
- Deals
- Matching
- AI assistance

## Architecture

Telegram
    ↓
Telegram Adapter
    ↓
SmartMelk Core
    ↓
PostgreSQL
    ↓
Matching Engine
    ↓
AI / RAG
